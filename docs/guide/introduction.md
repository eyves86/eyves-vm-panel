# 项目介绍

**EyvesCloud** 是一个企业级多节点虚拟化云管理平台，面向 LXC / KVM 混合工作负载。它将分散的宿主机运维动作收敛为统一控制平面，以 Web 控制台、CLI 与版本化 REST API 三种形态对跨节点工作负载实施全生命周期管理。平台内置调度引擎、多租户隔离、计量对接与安全审计能力，适合 VPS 服务商、企业基础设施团队、研究实验室以及需要批量开通和分发容器访问权限的场景。

## 产品定位

- **统一控制平面**：单一主控纳管无限被控节点，控制台 / CLI / API 三端一致，跨节点操作无需逐台登录。
- **计量与财务就绪**：全量用量导出 API（资源配置 + 实时用量 + 到期/流量），配合幂等开通机制，可直接对接计费系统。
- **企业级多租户**：子用户（operator / viewer 角色）按容器授权、租户配额、独立面板入口、令牌版本控制。
- **安全纵深**：conntrack 威胁检测、JWT Issuer/Audience 绑定、API Key scope 细粒度授权、全量操作审计与登录日志。

## 核心能力

### 计算与编排

- 统一管理 LXC 容器和 KVM 虚拟机：创建、开机、关机、重启、重装、删除、重置密码、挂起/恢复与批量操作。
- 智能调度引擎：过滤（在线 / 容量 / 存储后端 / 维护模式）→ 评分（RAM + Disk + 租户分散度）→ 决策留痕。
- 主控-被控多节点：主控生成一键安装脚本，被控服务器执行后自动注册接入，主控可直接查看/操作被控工作负载。
- 生命周期治理：到期或流量超额自动关机。

### 网络与存储

- NAT4 端口配额、随机可用端口、TCP/UDP 端口映射、公网 IPv4 池管理。
- 宿主机具备 IPv6 路由时分配公网 IPv6，支持前缀检测与状态巡检。
- 存储池管理（dir / ZFS / LVM / RBD / CephFS / NFS）、资源配额与策略引擎，支持租户隔离与按容器授权。

### 资源治理

- CPU、内存、磁盘、Swap、独立上下行带宽、读写 I/O 限速与流量限制。
- 快照创建、恢复、删除，计划快照与快照配额。

### 安全与合规

- 基于连接行为的安全告警（端口扫描、爆破、SMTP 滥用、挖矿端口等）。
- 操作审计日志与登录日志，WebSSH 来源白名单与面板访问策略。

### 自助与集成

- 为指定容器创建子用户访问链接，支持查看/操作角色与可用镜像限制。
- 通过 API Key 接入 `/api/v1` 自动化接口，`GET /api/v1/usage` 对接计量。
- 浏览器内直接打开 WebSSH 或 WebVNC。

## 适用场景

| 场景 | 说明 |
| --- | --- |
| VPS 服务商 | 主控纳管多机房节点，子用户自助管理名下实例，用量 API 对接财务计费，实现开通-计量-停复机闭环。 |
| 企业基础设施团队 | 多租户隔离 + 角色授权 + 全量审计，为开发/测试团队交付自服务平台，安全策略集中管控。 |
| 实验室与教育机构 | 批量开通 + 模板管理 + 到期自动回收，低成本支撑批量实验环境。 |
| 开发者自托管 | 单节点 5 分钟部署，WebSSH/WebVNC 浏览器直连，无需额外跳板机。 |

## 技术栈

- **控制面**：Go（`net/http`）、PostgreSQL（配置库与遥测）、调度引擎。
- **虚拟化层**：LXC、KVM/libvirt、cgroup v2、iptables、conntrack。
- **数据面**：React、TypeScript、Vite、Tailwind CSS、lucide-react、xterm.js、noVNC。
- **交付**：Linux（systemd / OpenRC）、GitHub Actions 构建 Linux AMD64/ARM64 release 产物，安装脚本默认拉取最新 Release。

## 原创性说明

EyvesCloud 是**独立编写**的开源项目：后端（Go）、前端（React/TypeScript）、被控 Agent、主控-被控代理协议、REST API、策略引擎与安全引擎均为本仓库从零实现，不存在对任何既有面板的源代码复用或复制粘贴。

需要澄清的几点：

- **命名与标识**：产品名 "EyvesCloud" 为本项目自有命名，与任何第三方产品或商标无关。
- **可借鉴但不抄源码**：项目在「主控-被控节点」「NAT/IPv6 网络」「WebSSH/WebVNC」等常见场景的**功能形态**上与部分同类产品相似，这是行业通用需求，并非代码抄袭。其**实现方式**（[架构文档](../developer/architecture.md)）为自主设计，包括 PostgreSQL 持久化模型、JWT + API Key（argon2id）鉴权体系、节点 token 代理协议、基于 TOTP 的两步验证、策略引擎与基于 conntrack 的安全引擎等均有单独落地。
- **依赖的第三方组件**：仅使用 Go 标准库/知名开源库（如 `golang.org/x/crypto`、`github.com/jackc/pgx/v5`）、React 生态与 Linux 系统组件（LXC、libvirt、iptables），各自遵循其开源许可。
- **文档**：本文档站与 [README](../../README.md)、[部署文档](../../DEPLOYMENT.md) 均为本项目原创撰写。
