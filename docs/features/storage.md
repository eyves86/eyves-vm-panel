# 存储管理

存储管理用于配置和管理宿主机上的存储池（Storage Pool）。存储池是容器、镜像、快照和备份的实际存放位置。

## 存储池

默认安装会创建一个主存储池：

| 配置 | 默认值 |
| --- | --- |
| ID | `disk-root` |
| 名称 | `system (/)` |
| 路径 | `/var/lib/eyvescloud` |
| 挂载点 | `/` |
| 内容类型 | LXC、KVM、镜像、快照、备份 |

存储池支持以下内容类型：

- `lxc`：LXC 容器根文件系统。
- `kvm`：KVM 磁盘镜像。
- `images`：镜像缓存。
- `snapshots`：快照。
- `backups`：备份。

## 多存储池

可以在「存储管理」页面添加多个存储池，例如把容器放到数据盘：

| 配置 | 示例 |
| --- | --- |
| ID | `disk-data` |
| 名称 | `data disk (/data)` |
| 路径 | `/data/eyvescloud` |
| 挂载点 | `/data` |
| 内容类型 | LXC、镜像 |

每个存储池可独立设置「默认内容类型」，创建容器或下载镜像时会优先选择默认池，其次按剩余空间从大到小选择。

## 选择逻辑

创建容器或下载镜像时，系统按以下顺序选择存储池：

1. 用户显式指定的存储池（若空间充足）。
2. 配置为默认且空间充足的存储池。
3. 任意空间充足的存储池（按可用空间降序）。

存储池空间不足（预留 256MB 安全余量）或未挂载时会被跳过。挂载点检查依赖 `findmnt`，请确保目标挂载点已正确挂载。

## 相关接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/storage` | 查看存储池与磁盘状态 |
| PUT/POST | `/api/storage` | 更新存储池配置 |

`/api/v1/storage` 提供版本化接口。
