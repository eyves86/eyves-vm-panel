# 节点迁移

节点迁移用于在服务器之间搬运容器配置。它通过「导出迁移包 → 目标节点导入」的方式完成，迁移包内包含容器配置（网络、端口映射、SSH 信息等），导入后即可在目标节点继续管理。

## 导出迁移包

1. 进入「节点迁移」页面。
2. 在容器列表中选择要迁移的容器，点击「导出」。
3. 浏览器会下载一个 `<容器名>.migrate.json` 文件。

导出的是容器配置快照，不包含 rootfs 数据。如需迁移数据，请先在源节点创建快照或自行备份容器数据目录，再在目标节点恢复。

## 迁移增强

- 完整性校验：导出时会为容器配置计算 SHA256 校验和（`checksum_sha256`），导入时进行校验，防止迁移包在传输或拷贝过程中损坏或篡改；校验失败会拒绝导入并提示重新导出/下载。
- 数据盘迁移：迁移包携带数据盘大小 `data_disk_gb` 与挂载路径 `data_disk_mount_path`，导入时按原配置重建数据盘。
- 迁移包版本与格式：导出格式为 `eyvescloud-migrate`，当前 bundle 版本 v2。

## 导入迁移包

1. 在目标节点的「节点迁移」页面，选择导出的 `.migrate.json` 文件。
2. 页面会解析迁移包并显示容器信息。
3. 确认后点击「导入」，目标节点会根据配置重建容器记录。

导入后检查容器状态、网络和端口映射是否与源节点一致。

## 使用场景

- 更换宿主机或迁移到更大配置的服务器。
- 同一主控下把容器从一台被控节点搬到另一台。
- 容灾演练：定期导出配置，需要时快速恢复。

## 相关接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/migrate/export/{id}` | 导出容器迁移包 |
| POST | `/api/migrate/import` | 导入迁移包 |

`/api/v1/migrate/import` 也提供版本化导入接口。
