# 审计日志

审计日志记录管理员和子用户在面板上的关键操作，便于回溯与合规审计。

## 记录内容

每一条审计日志包含：

| 字段 | 说明 |
| --- | --- |
| 时间 | 操作发生时间。 |
| 操作 | 动作标识，如 `container.create`、`node.create`、`policy.create` 等。 |
| 目标 | 操作对象，如容器名、节点名。 |
| 详情 | 操作描述。 |
| 用户 | 操作人（管理员或 `user:<子用户>`）。 |
| IP | 操作来源 IP。 |
| 结果 | 成功 / 失败，失败时附带错误信息。 |

## 覆盖范围

- 容器创建、删除、重装、开关机、重置密码。
- 节点创建、删除、注册。
- 子用户创建与权限变更。
- API Key 创建与删除。
- 策略、存储、路由、快照等管理操作。
- 管理员密码修改等敏感操作。

系统最多保留最近 500 条审计日志，同时会持久化到 SQLite，重启不丢失。

## 登录日志

「审计日志」页面同时提供登录日志，记录每次登录的时间、用户名、来源 IP 和成功状态，用于发现异常登录。

## 相关接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/audit-logs` | 审计日志列表 |
| GET | `/api/login-logs` | 登录日志列表 |

`/api/v1/audit-logs` 和 `/api/v1/login-logs` 提供版本化接口。
