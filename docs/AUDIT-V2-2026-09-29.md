### 2.2 鉴权与越权检查

| 检查项 | 结论 |
| --- | --- |
| 未认证访问受保护端点 | 401 `UNAUTHENTICATED`（AuthMiddleware 统一拦截） |
| 子用户访问管理员端点 | 403 `PERMISSION_DENIED`（`v2RequireAdmin` / scope 双重校验） |
| API Key 授予范围超出自身 | 403（`validateKeyGrantScopes` 拒绝管理类 scope 与越权授予） |
| 容器绑定密钥访问他人实例 | 403（`v2FindInstance` → `isContainerAllowedForRequest`） |
| Webhook 回调地址 SSRF | 拒绝回环/链路本地（含云元数据 169.254.169.254）/组播/保留段（复用 `safehttp.ValidateURL`） |
| 节点 SSRF | `validateNodeAddress` 逐条校验解析后的 A/AAAA，解析失败按拒绝处理 |
| 常规时间比较 | 节点 token 用常量时间比较；v2 复用同一 `AgentTokenMiddleware` |

### 2.3 边界与健壮性

- **参数校验**：`runtime=hyperv` → 400 + `details.runtime` + `request_id`；非法端口/CIDR/方向/协议均被拒。
- **状态前置**：锁定实例拒绝删除/重装（412 `PRECONDITION_FAILED`）；挂起/到期/超流量实例拒绝开机。
- **被控通信失败**：返回 502 `UPSTREAM_ERROR` 并附被控原始错误，便于定位。
- **凭据脱敏**：节点列表/详情不含 token / install_key；Webhook 列表不含 secret；API Key 明文仅创建时返回一次。
- **分页上限**：`page_size` 上限 200，防止大页拖垮响应。
- **审计留痕**：所有写操作落审计（含 actor/IP/UA），API Key 与子用户可追溯。

### 2.4 待办（需先补底层能力，非缺陷）

### 3.2 发现问题

**【中危 · 已修】英文界面中英夹生文本（i18n 自动翻译缺陷）**

- 现象：英文模式下出现 `In task心`、`历史run记录`、`已Cancel` 等破损文本
- 根因：`utils/i18n.ts` 按词条做**子串替换**——`任务中心` 被更短的 `任务中`（→`In task`）截断；正则替换先于词典执行，`运行` 被换成 `run` 后复合词条再也匹配不上
- 修复：① 词典匹配改**贪婪最长匹配**；② 执行顺序改「词典优先 → 正则兜底」；③ **翻译结果残留中文即整句保留原文**（宁可显示干净中文，不输出半截混合）
- 复验：英文任务页混排样本由 6+ 处降为 **0 处**；已收录标签仍正常英文（Task Center / Queued tasks / Completed / Failed / Refresh）

**【低危 · 已加固】按钮未按权限点渲染**

- 现象：只读子用户/受限 API Key 场景下，按钮仍显示，点击后才返回 403
- 加固：`AuthContext` 引入 `/api/v2/auth/me` 的 `features`，容器页「创建容器」按 `instance_create` 渲染；v2 不可用时回退旧判断（避免误伤）
- 建议后续：把 detail 页的电源/重装/控制台按钮也接入同一套 `can()` 判断

**【提示】版本提示与发布不同步**

- 现象：面板提示"有更新"，因为本地部署版本高于已发布 Release
- 处置：已发布 v2.2.8 对齐；后续每次部署后同步发布即可

### 3.3 已复核未发现问题的项

- 会话安全：`HttpOnly + SameSite=Lax` Cookie、前端不再持久化 JWT（审计 H-6 修复保持有效）
- 创建向导：目标节点选择（本机 / 自动调度 / 指定节点）与远程提示正常；节点列表与调度预览已接 v2 并带 v1 回退
- 面板内 v2 面板：105 端点清单 + 7 个只读端点试跑可用（实测 `/metrics/summary`、`/nodes/schedule` 返回真实数据）
